# SUMMONER-βversion / Online Beta2 v40

ブラウザカードゲーム SUMMONER。ローカル対戦は `summoner.html`、秘匿情報ありのオンライン対戦は `online.html`。

## v40
- タイトルにβ版の注意書きを表示。オンラインロビーから不要な効果処理確認表示を除去。
- 召喚士はカード選択後に「効」マーカーで能力発動。
- 投了確認追加（指示どおり YES=戻る、NO=投了）。スマホとPCからアクセス可能。
- モンスターの手動タップ・アンタップ禁止（オンライン版）。相手召喚士をクリックして直接攻撃。
- カード詳細小窓、縦向き流脈アイコン、召喚酔い表示、選択順番号を追加。
- 登場時効果は召喚のスタック解決**後**に新たなスタックとして発動し、追加の優先権確認を行う。
- スマホで相手側カードゾーンを奥方向へ調整。
- 更新履歴の表示をクリア。
- ルームコードを英数字6桁に変更（以前の12桁コードとの互換なし）。

### 重要
GitHub PagesとCloudflare Workersの**両方**を更新してください。`ONLINE_UPDATE_v40.md` を参照。
Workerの `/health` は `alpha2-v40` である必要があります。`online-config.js` は上書き不要です。

通常デッキ50枚＋召喚士1枚、初期デッキ7種類とアップロード指定の `SUMMONER_Rulebook_Beta.pdf` は維持します。オンライン対戦では相手の手札・山札の実カード内容は送信されません。

オンライン対戦エンジンはローカル版と独立しており、全カードの例外的な裁定や実運用の全局面まで完全一致が確認できているわけではありません。
