# SUMMONER — Mobile / PWA Playtest

SUMMONER のPC・スマホ両対応版です。
## このローカルテスト版のルール変更

- デッキは **最大50枚**
- 旧「流脈カード」→ **召喚士カード**
- 旧「流脈ゾーン」→ **召喚士ゾーン**
- 旧「マナ」→ **陣**
- 召喚士カードも他のカードと同じく、**同名カードは最大4枚**。召喚士カード全体の枚数上限はありません（デッキ全体は最大50枚）
- 召喚士ゾーンのカードは、従来どおりタップして陣を生成します
- 正規の召喚士カードは「陣生成」か「タップして固有効果」のどちらかを選びます。各色5種、合計25種の召喚士カードを実装済みです
- 指定された既存カード15種をカードプールから削除（通常カード105種＋召喚士25種＝計130種）
- 通常カードを裏向きで召喚士ゾーンに置く従来の処理は維持しています
- デッキ構築画面の**デッキ一覧のみ**、枚数順 / コスト順でソート可能（カードプール側は基本順固定）
- アイコン：モンスター `△` / 魔法 `✦` / 召喚士 `◎` / 高速詠唱 `⚡`
- 対象を取る効果は対象決定後にスタックへ置き、両者PASS後はスタックを上から最後まで連続解決します。召喚士の起動能力も同じ方式でスタックに置かれます
- 効果解決中に必須選択がある場合はキャンセル不可（例：ルフナの山札上3枚並べ替え）
- ジルコニアの強制攻撃：対象が有効で攻撃可能なモンスターがいる限り、相手はバトルフェイズを行い可能なら指定対象へ攻撃する
- モンスターを攻撃した場合も、守備側は通常どおりブロック可能
- 《詠唱破棄》は召喚士以外の相手カードのみ無効化可能


## 召喚士能力のコスト

- `タップ：赤の陣＋1` など：その召喚士自身をタップして対応色の陣を1つ生成
- `タップ＋◎1` / `タップ＋◎2`：その召喚士自身をタップし、さらに色を問わず陣を1つ / 2つ支払って能力を発動
- 誘発条件を持つ召喚士は、条件成立時に発動するか選択します

## PCで遊ぶ

これまで通り、ZIPを展開して `index.html` を開けばローカルで遊べます。

> `file://` で直接開いた場合、ゲーム本体は動きますがPWAのインストール・Service Workerによるオフラインキャッシュは利用できません。

## スマホで遊ぶ（推奨）

GitHub Pagesで公開して、そのURLをスマホで開きます。

### GitHub Pages

1. このフォルダの中身をGitHubリポジトリのルートにアップロードします。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. 公開元を `main` ブランチ / root に設定します。
4. 発行されたGitHub PagesのURLをスマホで開きます。

### Android

ChromeなどでSUMMONERを開き、ブラウザのメニューから
「アプリをインストール」または「ホーム画面に追加」を選択します。

対応ブラウザではタイトル画面にも
「SUMMONERを端末にインストール」ボタンが表示されます。

### iPhone / iPad

SafariでSUMMONERを開きます。

**共有 → ホーム画面に追加** を選択してください。

## オフライン動作

GitHub Pagesから一度正常に読み込むと、主要ファイルが端末にキャッシュされます。
その後は、キャッシュが残っている範囲でオフライン起動できます。

オンライン対戦機能はありません。
PLAYER 1 / PLAYER 2 は従来通り同じ端末上で操作します。

## スマホ版の変更

- 対戦画面をスマホ幅に自動最適化
- PLAYER 1の手札を画面下部に固定
- 手札を縮小 / 展開可能
- DRAW / BATTLE / NO BLOCK / PASS / END を固定操作バーに配置
- スタック / ログへ移動するボタンを追加
- 対象選択をスマホ向けの大きなボタンに変更
- デッキ構築を1カラム化
- カード詳細に「＋ デッキに追加」を追加
- PCのドラッグ＆ドロップ操作はそのまま維持
- PWA / ホーム画面追加対応
- Service Workerによるオフラインキャッシュ対応

## 保存データ

ユーザーやデッキは `localStorage` に保存されます。
そのためPC・スマホ・ブラウザごとに保存データは別です。

ブラウザのサイトデータを削除するとデッキも削除される可能性があります。
