ブラウザカードゲーム SUMMONER。ローカル対戦は `summoner.html`、秘匿情報ありのオンライン対戦は `online.html`。

### 重要
GitHub PagesとCloudflare Workersの**両方**を更新してください。`ONLINE_UPDATE_v40.md` を参照。
Workerの `/health` は `alpha2-v40-triggerfix-20261026` である必要があります。`online-config.js` は上書き不要です。

通常デッキ50枚＋召喚士1枚、初期デッキ7種類とアップロード指定の `SUMMONER_Rulebook_Beta.pdf` は維持します。オンライン対戦では相手の手札・山札の実カード内容は送信されません。

オンライン対戦エンジンはローカル版と独立しており、全カードの例外的な裁定や実運用の全局面まで完全一致が確認できているわけではありません。

## v43（2026-11-02） — 発動可否に応じた自動PASSと切り替え
- 【高速詠唱】を持っていても、現在の優先権でコスト・色・LP・対象・対応条件を満たせず発動できない場合は自動PASS。
- 未タップの流脈から必要なマナを生成できる場合は、優先権を維持して流脈をタップできる。
- 自動PASSはオンライン版では各プレイヤー個別、1人回し版では共通設定としてON/OFF可能。
- 初期設定はON。OFFにすると従来どおり手動PASS。

## v45（2026-11-03）— 1人回しAI対戦
- 1人回しのPLAYER 2をAIが操作するモードを追加。デッキ選択画面でON/OFF可能（初期設定ON）。
- AI難易度「標準／強い／最強」を追加。初期設定は「強い」。
- AIはブラウザ内のJavaScriptで動作し、外部API・APIキー・有料サービスを使用しない。
- 自分の手札・山札・墓地・盤面・流脈・マナを評価し、ビーム探索でメインフェイズのカード使用順を決定。
- 攻撃時は相手のブロック候補を想定した戦闘評価を行い、ブロック時もPower・SP・炸裂・LP被害を比較して判断。
- 召喚・スペル・召喚士能力の対象選択、カード検索、手札整理、ターン終了誘発、ドロー処理を自動化。
- 相手の手札と山札のカード内容はAIの判断材料に含めず、枚数と公開情報のみを使用。
- Web Workerやサーバーを必要とせず、GitHub Pages版にそのまま配置できる構成。

### AIの実装方式と注意
AIは自己対戦で学習済みのニューラルネットワークではなく、SUMMONERのカード・ルールに合わせた評価関数、ビーム探索、攻防の読みを組み合わせたローカル探索AIです。「最強」は探索幅と先読み深度を増やした設定です。カード効果の実際の処理は既存ゲームエンジンを利用します。
