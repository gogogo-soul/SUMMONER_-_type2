## カスタムフィールド画像（Beta2 v17）

対戦画面上部の **「フィールド」** から、任意の画像を盤面背景に設定できます。
標準状態は従来の **v17 白い卓上フィールド** です。「v17標準に戻す」でいつでも元に戻せます。

- **推奨サイズ：1920 × 1080 px（16:9）**
- 最低目安：1280 × 720 px
- 推奨形式：JPG / WebP / PNG
- 推奨容量：5MB以下（選択上限10MB）
- 画像は `cover` 表示のため、画面比率によって上下または左右が少しトリミングされます
- 選択した画像はその端末のブラウザ内（IndexedDB）へ保存され、次回起動時も維持されます

## 現行ルール（Beta2 v20：対戦仕様はv19と同じ）

- 初期LP20・初期手札7枚。通常デッキ50枚とは別枠の召喚士1枚を準備時に裏向きで置き、ゲーム開始時に同時公開する
- 通常デッキはちょうど50枚。モンスター／魔法は同名4枚まで、流脈は同名50枚まで。召喚士は別枠に1種類1枚だけ採用できる
- 自分のメインフェイズに、通常のプレイより先に流脈ゾーンへ1ターン1枚置ける。流脈カードは表向き、通常カードは裏向きで置ける
- タップした流脈は対応する色のマナを1つ生成。裏向き流脈は無色マナを1つ生成
- 色付きのカードはそのカードと同色のマナを最低1つ含めて支払う。未使用マナはターン終了時に消える
- 召喚士はマナを生まず、召喚士カードに書かれた固有能力だけを使用。能力コストに「マナ1」などとある場合は任意の色のマナで支払える
- 召喚士の能力はタップして発動し、条件付きの効果は条件成立時に発動するか選択できる
- ゲーム開始時の先攻を選べる。先攻プレイヤーは最初のターンのみ通常ドローなし
- 旧デッキは新ルールに合わせてデッキビルダーで修正する（召喚士を流脈に自動変換しない）
- カードプールは通常カード105種・召喚士25種・流脈5種、合計135種類
- 《ベリル》は流脈をアンタップする効果に、《ヨナ》は流脈が3枚以上ある場合の判定へ変更
- マナ・流脈・召喚士の参照箇所を新ルールに合わせて修正

## PCで遊ぶ

これまで通り、ZIPを展開して `index.html` を開けばローカルで遊べます。

> `file://` で直接開いた場合、ゲーム本体は動きますがPWAのインストール・Service Workerによるオフラインキャッシュは利用できません。

## スマホで遊ぶ（推奨）

GitHub Pagesで公開して、そのURLをスマホで開きます。

### GitHub Pages

1. このフォルダの中身をGitHubリポジトリのルートにアップロードします。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. 公開元を `main` ブランチ / root に設定します。
4. 発行されたGitHub PagesのURLをスマホで開きます。

### Android

ChromeなどでSUMMONERを開き、ブラウザのメニューから
「アプリをインストール」または「ホーム画面に追加」を選択します。

タイトル画面のインストール専用ボタンは廃止しました。必要な場合はブラウザの「ホーム画面に追加」または「アプリをインストール」を利用してください。

### iPhone / iPad

SafariでSUMMONERを開きます。

**共有 → ホーム画面に追加** を選択してください。

## オフライン動作

GitHub Pagesから一度正常に読み込むと、主要ファイルが端末にキャッシュされます。
その後は、キャッシュが残っている範囲でオフライン起動できます。

オンライン対戦機能はありません。
PLAYER 1 / PLAYER 2 は従来通り同じ端末上で操作します。

## 保存データ

ユーザーやデッキは `localStorage` に保存されます。
そのためPC・スマホ・ブラウザごとに保存データは別です。

ブラウザのサイトデータを削除するとデッキも削除される可能性があります。
