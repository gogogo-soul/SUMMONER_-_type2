更新内容

SUMMONER Beta2 の主な変更点をまとめています。新しい更新を公開したときは、このページへ追記します。

LATEST · Beta2 v17
Beta2 v17
対戦UI刷新・スマホ統一・更新内容ページ追加
LATEST
  • PC版の対戦画面を白いプレイマット風の卓上レイアウトへ刷新。
  • PLAYER 2を上、PLAYER 1を下に配置した上下対称レイアウトへ変更。
  • スマホ版もPC版と同じ白い卓上レイアウトへ統一し、縦画面・横画面の両方に対応。
  • PLAYER 1 / PLAYER 2 の手札カードを110×140へ統一し、カード名・ATK・HPが見えやすい位置と重なり方へ調整。
  • ATK / HP表示の視認性を改善し、上部ナビゲーション・各種ボタン・操作ドックを大型化。
  • 墓地をデッキの上へ配置し、Card Inspector / 解決待ち / Action Logを右側INFOパネルへ集約。
  • 《ルフナ》など効果解決時の案内・対象選択モーダルの見出し文字を白色へ変更。
  • タイトル画面の「端末にインストール」ボタンを「更新内容 (UPDATE NOTES)」へ変更。
  • 更新履歴専用ページを新設。今後の変更内容はこのページへ追記する形式に変更。
  • 対戦画面に「フィールド」を追加。v17標準盤面を維持したまま、端末内の好きな画像を背景に設定・保存・初期化できるように変更（推奨1920×1080 / 16:9）。
  • PWAとしてのホーム画面追加・Service Worker機能自体は引き続き利用可能。
Beta2 v16
DECK LIBRARYでデッキ内容を閲覧可能に
DECK LIBRARY
  • 投稿されたデッキの採用カード・枚数・識別番号・色・コストなどを閲覧可能に。
  • 一覧内のカードを選ぶとカード詳細・効果を確認可能。
Beta2 v15
DECK LIBRARY / Firebase連携
ONLINE
  • Firebase Firestoreを利用した共有デッキ置き場を追加。
  • デッキ名・投稿者名・コメント・デッキコードを投稿可能。
  • 「このデッキを使う」からDECK BUILDERへ直接デッキを展開可能。
  • Service Workerをオンライン時は最新版優先、オフライン時はキャッシュ利用へ変更。
Beta2 v14
カード公開後に優先権を渡す形式へ変更
RULE / UI
  • 手札の召喚士は1クリックで置かず、まずCard Inspectorで確認してから配置する方式へ変更。
  • モンスター・魔法は対応待ち中も盤面に公開し、相手が効果を確認してから対応できるよう変更。
  • 登場時効果を持つモンスターは場に出た後で対象を選ぶ処理へ変更。
Beta2 v13
効果解決中の盤面確認
DUEL
  • 《ルフナ》《深緑のシャーマン》など、必須選択中に「盤面を見る」を追加。
  • 盤面確認中は誤操作を防ぎ、確認後に効果処理へ戻れるように変更。
Beta2 v12
デッキコード共有
DECK
  • DECK BUILDERにデッキコード発行・コピー・読み込み機能を追加。
  • カード名ではなくBS01識別番号と枚数でデッキ構成を保存。
  • サーバー不要で別端末へデッキを共有可能。
Beta2 v11
カード表示と召喚士ゾーン表示を整理
UI
  • ATK / HPへ縁取りを追加し、キャンセル文字を黒色へ変更。
  • 召喚士ゾーンに現在のカード枚数を表示。
  • カード本体から効果テキストを外し、Card Inspectorで確認する形式へ整理。
Beta2 v10
先攻選択・LP支払いルール
RULE
  • ゲーム開始時にPLAYER 1 / PLAYER 2のどちらを先攻にするか選択可能に。
  • 先攻プレイヤーは最初のターンのみ開始ドローなし。
  • LP支払いカードは、支払い後にLPが1以上残る場合のみ使用可能。
このページはプレイテスト版の更新履歴です。ルール・カード効果・UIは今後も変更される場合があります。
